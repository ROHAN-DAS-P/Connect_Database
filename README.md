# User Management REST API

A simple REST API built using **Node.js, Express, and MySQL** to perform CRUD operations on users.  
This project demonstrate direct SQL handling and backend fundamentals.

---

## Features

- Create user
- Update user
- Delete user
- Get user by ID
- Get all users
- Pagination support
- UUID-based user IDs
- MySQL connection 

---

## Tech Stack

- Node.js
- Express.js
- MySQL
- mysql2
- UUID
